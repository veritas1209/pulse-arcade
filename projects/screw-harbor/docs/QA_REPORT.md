## 이전 공개 패치

최신 패치: 구조물 20종, 독립 부품 3,859개, 나사 7,718개. 기존 12종에 대형 구조물 8종을 추가했다. 새 나사 수는 600 / 480 / 520 / 640 / 640 / 800 / 560 / 720개다. 기존 수량과 색 수집 규칙은 유지했다.

임시 보관은 위쪽 수집함 옆에 배치했다. 오른쪽·가운데·Shift 드래그와 두 손가락으로 시점을 이동한다. 구조물 카드 이름은 이미지 위에 있다. 모든 부품에 실제 두께와 닫힌 단면을 만들었고, 마지막 나사까지 고정된다. 포털 설명은 “나사를 뽑아 구조물을 해체하세요.”로 줄였다.

빌드 및 자동 검사 **34/34 통과**: 규칙·인출 11개, 메시 5개, PC·모바일 기능 14개, 화면 회귀 4개. 20종 실제 마우스 **7,718/7,718**, 모바일 터치 3종 **1,292/1,292** 완주했다. 실제 휴대폰 검사는 별도다.

증거: `artifacts/large-structures/all-input-verification.json`, `artifacts/input-bot-mobile-stages-0-10-17.json`, `artifacts/october-rules`, `artifacts/october-solids`, `artifacts/october-functional`, `artifacts/october-visual`, `artifacts/large-structures/metrics.json`. 전체 마우스 기록은 관찰한 실행 출력에서 정리했다. 11번 여객선은 검사 도구의 좁은 시야 조준을 수정한 후 재실행해 336개를 완주했다. 게임 규칙을 완화하지 않았다.

메시 검사는 20종의 모든 독립 부품에 나사 2개, 닫힌 경계, 양의 부피, 유한 좌표, Float32 GPU 속성을 확인한다. 반복 절단의 부피 보존, 구멍의 단면·법선, 두께 있는 곡면과 공면 절단도 검사한다. 새 구조물 반경은 17~25이며 기존 모델은 4~6이다. 최대 초기 장면은 408 draw calls / 453,778 triangles다.

공개 파일 25개를 패키징하고 운영 릴리스 `20261001-screw-harbor-022956`에 반영했다. 기존 게임 6개와 파일 58개를 보존했다. 공개 HTTPS PC·모바일에서 25개 파일 해시, 실제 선택·재시작·일시정지, 위쪽 임시 보관, 시점 이동, 카드 이름 위치, 20종 목록, 336개 여객선과 800개 항공모함 진입, 짧은 포털 설명과 허브 복귀를 확인했다. 게임 오류 없음. 기존 허브의 favicon.ico 404는 별도 기록했다. 배포용 Tailscale 계정을 원래 계정으로 복원했다. 증거는 `artifacts/deployment/deployment.json`, `public-verification.json`과 공개 화면 이미지다.

## 동작

- 12개 구조물. 독립 부품 1,379개, 나사 2,758개.
- 구조물별 나사: 156 / 168 / 180 / 192 / 204 / 252 / 220 / 232 / 290 / 252 / 336 / 276.
- 모든 구조물에 5색. 수집함 2개, 색마다 3개. 다른 색은 임시 5칸으로 이동.
- 색이나 해체 단계로 나사를 잠그지 않음. 실제 가림과 인출 공간으로 판단.

- 부품은 마지막 나사까지 고정. 모든 나사를 제거하면 빠지며 사라짐.
- 힌트·되돌리기 없음. 회전, 확대, 재시작, 일시 정지, 음량/모션 설정 제공.
