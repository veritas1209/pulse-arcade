## 제작·화면 검토

기존 밝은 모형 퍼즐 스타일을 유지하며 구조와 내부를 보강했다. 복잡한 선박·기단은 Astra 에이전트, 재질 아틀라스와 독립 화면 검토는 5.6 Sol 에이전트, 통합·카메라·검증은 기본 모델이 담당했다. Director, AAA graphics, gameplay, 3D/image generator, QA skills를 참고했다.

생성기 실행 환경 확인 결과 `TRIPO_API_KEY=MISSING`, `GEMINI_API_KEY=MISSING`. 해체 가능한 개별 부품을 유지하는 직접 제작 메시와 재현 가능한 절차적 PBR 지도를 사용했다. 생성 스크립트와 해시는 `docs/material-atlas.md`, `public/materials/surface-atlas.json`에 있다.

독립 이미지 검토에서 내부 구획·설비와 받침판 제거를 확인했다. 가까운 확대에서 재질이 선명하며 기본 거리에서는 나사 판독을 우선한다. 밝은 벽과 설비의 명암 차, 모바일 기본 화면의 작은 모델 크기는 남은 개선점이다. 검사 화면의 과도한 확대는 촬영 거리만 조정했다.

최대 초기 장면은 항공모함 405 draw calls / 481,342 triangles. 기본 집은 83 calls / 103,494 triangles, GPU 텍스처 7개. Intel UHD/ANGLE에서 PC·터치 에뮬레이션을 확인했다. 대형 구조물은 모바일 기본 예산 150 calls / 300,000 triangles를 초과하며 실제 휴대폰 성능은 측정하지 않았다.
