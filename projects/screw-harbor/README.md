# SCREW HARBOR / 스크루 하버

집·건물·기념물·우주선·배를 해체하는 3D 나사 퍼즐. 20개 구조물, 나사 156~800개.

배와 우주선에는 객실·기관실·격납고와 분리되는 내부 부품이 있습니다. 목재·금속·석재 등 8종 PBR 재질을 적용했습니다. 전시 받침판은 제거했고 자유의 여신상 바닥은 닫혀 마지막에 해체됩니다.

[Pulse Arcade에서 플레이](https://222.96.173.194/games/screw-harbor/). 이후 패치도 Pulse Arcade에 반영합니다.

## 빠른 로컬 실행 (Windows)

프로젝트 의존성이 이미 설치되어 있으면 루트의 `Start-Game.cmd`를 더블 클릭하세요. 이 도구는 `dist/`가 없을 때 로컬 의존성으로 빌드하고, `http://127.0.0.1:4188`에서 프로덕션 미리보기를 제공합니다. 서버를 종료하려면 열린 콘솔에서 `Ctrl+C`를 누르세요. 필요한 의존성이 없으면 설치를 시도하지 않고 안내만 보여 줍니다.

## 개발 실행 및 빌드

필요 환경: Node.js 20.19+ 또는 22.12+ (Vite 8), npm. 설치 의존성이 없는 새 개발 환경에서:

```sh
npm install
npm run dev
```

개발 서버 기본 주소는 `http://127.0.0.1:5188`입니다. 프로덕션 산출물과 미리보기는 다음과 같습니다.

```sh
npm run build
npm run preview
```

미리보기 기본 주소는 `http://127.0.0.1:4188`입니다. `npm` 명령을 사용할 수 없으면 아래 번들된 pnpm 실행기를 사용하세요.

```powershell
& 'C:\Users\hajin\.cache\codex-runtimes\codex-primary-runtime\dependencies\bin\fallback\pnpm.cmd' install
& 'C:\Users\hajin\.cache\codex-runtimes\codex-primary-runtime\dependencies\bin\fallback\pnpm.cmd' run dev
```

게임 빌드는 정적 클라이언트 산출물입니다. 플레이에 계정이나 원격 서버가 필요하지 않습니다.

## 조작

- 마우스 또는 터치로 보이는 나사를 선택합니다. 색이나 현재 상자와 관계없이 가림이 없는 나사는 선택할 수 있습니다. 현재 상자 색과 맞으면 상자에 들어가고, 맞지 않으면 임시 보관함에 놓입니다.
- 드래그로 회전합니다. 오른쪽·가운데 버튼 또는 Shift 드래그로 시점을 이동하고 휠로 확대합니다. 터치는 한 손가락 회전, 두 손가락 이동·확대입니다.
- 최대 확대는 기존보다 28배 가까워져 내부와 표면을 살펴볼 수 있습니다.
- 카메라는 남아 있는 벽을 통과하지 않습니다. 외피와 방의 벽을 해체해 내부 나사를 드러내며 진행합니다.
- 키보드 방향키로 시점을 회전합니다. `R`은 현재 스테이지 재시작, `Esc`는 일시정지입니다.

나사는 바깥쪽으로 빠져나올 머리의 경로가 부품에 막히지 않을 때 선택할 수 있습니다. 경로가 막힌 나사를 누르면 흔들림으로만 반응하고 게임 상태는 바뀌지 않습니다. 부품은 나사가 남아 있는 동안 고정되며, 모든 나사를 뽑으면 빠져 사라집니다. 제거한 나사는 색이 현재 상자와 맞으면 그 상자로, 다르면 임시 보관함으로 이동합니다. 위쪽 수집함 옆에 있는 보관함은 5칸이며, 가득 차면 실패합니다. 이 게임에는 힌트와 되돌리기가 없으므로 상자 색과 가림이 풀릴 순서를 살펴 선택하세요.

## 로컬 사용자 점검과 테스트

먼저 아래 개발 체크를 실행하고 브라우저에서 직접 플레이하세요. 검증한 패치는 사용자의 요청에 따라 Pulse Arcade에 반영합니다.

```sh
npm run test:rules
npm run test:functional
npm run verify:visual
```

시각 기준선은 프로젝트의 visual 테스트에 포함됩니다. 이 프로젝트에 아직 등록되지 않은 명령이라면 완료 전까지 실행할 수 없습니다. Windows에서는 `Start-Game.cmd`로 연 프로덕션 미리보기에서도 테스트하세요. 추가 점검 항목은 [docs/pulse-deployment.md](docs/pulse-deployment.md)에 있습니다.

## Pulse 파일 준비

성공적으로 빌드한 뒤 `node scripts/prepare-pulse.mjs`를 실행하면 `dist/`의 허용 파일만 `release/pulse/screw-harbor/`로 복사하고 SHA-256 체크섬이 든 `manifest.json`, 포털 검토용 `catalog-entry.json`을 만듭니다. 기존 출력 경로가 있으면 덮어쓰지 않고 중단합니다. 네트워크에 접속하거나 Pulse 포털·서버 게임 목록을 수정하지 않습니다. 최신 패키지는 `node scripts/refresh-pulse.mjs`로 갱신합니다. 운영 반영과 원격 기준선 병합 절차는 [docs/pulse-deployment.md](docs/pulse-deployment.md)를 참고하세요.




검증 결과와 측정 자료: [QA_REPORT.md](docs/QA_REPORT.md). 테스트는 시스템 Chrome을 사용합니다. 기능 테스트는 개발 서버와 Pulse 경로 검증 서버를 자동으로 준비합니다. 사용자 실제 기기 플레이는 아직 별도 확인이 필요합니다.
